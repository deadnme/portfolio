Featured project

Twitch Emote No-Restart

  • v2.5.1
  • 1,378 lines
  • 0 dependencies
  • GPL-3.0
  • Vanilla JS
  • Published on Greasy Fork

The problem. Animated Twitch, 7TV, BTTV and FrankerFaceZ emotes are ordinary <img> elements, each animated independently by the browser. Twitch’s chat DOM churns constantly, and every churn snaps every on-screen copy of an emote back to frame 0 — so a busy chat visibly flickers.

The approach. Never let the browser animate the image at all. A MutationObserver recognises emote images by four CDN patterns, upgrades each URL to its highest-quality variant, fetches it (with a GM_xmlhttpRequest fallback when a CDN’s CORS headers are unfriendly), and decodes it frame by frame through the WebCodecs ImageDecoder API. Every copy of a given emote then shares one clock — a single start time, set once, which later copies may read but never rewind. The original image is hidden with opacity: 0 and a <canvas> is painted in one fixed overlay, with occlusion reconstructed from hit-testing and CSS clip-path insets.

What I learned building it. Most of the work was profiling, not writing features. A test harness running at 20 messages/second showed the first version forcing thousands of synchronous layout reads per second; fixing that meant splitting every frame into a strict read phase and write phase, taking exactly one bounding-rect measurement per instance per frame, and capping occlusion sampling to a 3 ms round-robin budget. An emote that misses that budget keeps a stale crop but still gets a fresh position, so it can never drift away from its image. Memory is bounded by an LRU that evicts only emotes nobody can see — evicting a visible one would restart it, which is the bug the whole script exists to prevent. Every failure path falls back to the native image rather than leaving a hole.

Profiling drove the last two releases: roughly 7,900 forced hit-tests and 6,700 style recalculations per second were eliminated, under a 3 ms per-frame occlusion budget and a 192 MB image-bitmap cache.
